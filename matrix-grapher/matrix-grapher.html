Matrix Grapher

How to use Matrix Grapher

1. Make a shape

  • Type it in a row: a point (2, 3), a polygon [(0,0),(3,0),(0,2)], or a line y=2x+1, x=3, 2x+3y=6.
  • Drag its points (or the whole polygon) on the graph to move it.

2. Transform it

  • Under the shape, press + matrix transformation and type the numbers of a matrix. The last column (shift) is for translations. You can type things like cos(pi/4) or 1/2.
  • The app works out what the matrix does (rotation, reflection, dilation, stretch, shear, translation, projection onto a line...). Tick Show transformation name to see it.
  • The original shape is solid with filled points. Each transformed image is dashed with hollow points.
  • Add several transformations to the same shape to chain them, or use Presets… for a quick start. ▶ animates.

Navigate

  • Drag the background to pan, scroll to zoom, ⌂ resets the view. Click a colored circle to hide or show something.
